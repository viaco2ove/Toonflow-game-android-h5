# h5 安卓app 的文字输入
webview 加载h5页面后，输入法与输入框的遮挡问题
不做处理连个h5 浏览器访问都不如！

浏览器（Chrome）：键盘弹出 → 视口变小 + 自动滚动，输入框自动进入可视区。
WebView 默认：
adjustPan：只平移，底部输入框仍会被挡。
adjustResize：全屏主题下直接失效（Android 原生 Bug）。
页面用 100vh：键盘弹出后高度不变，内容被挤在下方。

原生 + 前端：和浏览器体验一致，输入框自动上移、不遮挡、光标可见。


# 解决方案
原生端通过手动修改 WebView Layout 尺寸，去模拟系统丢失的 adjustResize 行为，从而让 H5                                                                    
端感知到真实的窗口变化，剩下的事情交给浏览器默认行为去解决。这样才能做到真正的“和浏览器访问体验一致”。

要彻底解决安卓H5端长按出现系统默认“选择复制”菜单的问题，需要从**事件拦截**和**CSS样式**两个层面进行处理。

既然你的项目已经实现了自定义的长按菜单（`openMenu`），且底部有自定义的语音长按按键，你需要完全屏蔽系统原生的长按行为（`contextmenu` 和文本选中）。

以下是具体的修复方案：
## 重点
不要使用默认的浏览器  
改用 chrome 和edge

### 1. 修改 `ScenePlay.vue` (拦截原生菜单事件)

在安卓端，仅靠 `pointerdown` 无法阻止系统长按事件的派发。你需要在模板中对**语音按钮**和**聊天气泡**显式拦截 `contextmenu`（右键/长按弹窗）事件，并阻止默认的 `pointerdown` 行为。

找到 `<template>` 中的 `.android-voice-btn`，添加 `@contextmenu.prevent` 和 `@pointerdown.prevent`：

```html
<button
  type="button"
  class="android-voice-btn"
  ...
  @pointerdown="onAndroidVoiceStart"
  @pointermove="onAndroidVoiceMove"
  @pointerup="onAndroidVoiceEnd"
  @pointercancel="onAndroidVoiceEnd"
  @pointerleave="onAndroidVoiceEnd"
>

<button
  type="button"
  class="android-voice-btn"
  ...
  @pointerdown.prevent="onAndroidVoiceStart"
  @pointermove="onAndroidVoiceMove"
  @pointerup="onAndroidVoiceEnd"
  @pointercancel="onAndroidVoiceEnd"
  @pointerleave="onAndroidVoiceEnd"
  @contextmenu.prevent
>

```

### 2. 修改 `styles.css` (禁用原生文本选中)

截图显示，长按时系统选中了气泡中的文字（“混沌虚空裂缝翻涌...”）。因为你的代码中已经用 `handlePressStart` 实现了自定义的长按弹出菜单，所以必须在 CSS 中彻底禁用剧情卡片的原生长按高亮和文本选择。

在 `styles.css` 中找到 `.play-bubble` 和 `.play-live-card`，补充以下 `-webkit-` 相关的属性：

```css
.play-bubble {

  padding: 13px 14px;
  border-radius: 16px;

  line-height: 1.6;
```

### 3. (可选) 处理 JS 中的默认事件

如果你发现长按语音按钮时偶尔还会触发页面的轻微滚动或其它异常，可以在 `ScenePlay.vue` 的 `onAndroidVoiceStart` 方法首行手动调用一次防范：

```typescript
function onAndroidVoiceStart(e: PointerEvent) {
  // 防御性阻止默认行为
  if (e.cancelable) {
    e.preventDefault();
  }
  
  if (!canPlayerInput.value || voiceTranscribing.value) {
    alert("无法录音: canPlayerInput=" + canPlayerInput.value + " voiceTranscribing=" + voiceTranscribing.value);
    return;
  }
  // ...原有逻辑
}

```
